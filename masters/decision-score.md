# 决策评分机制

## 评分维度

针对不同问题类型，使用不同的评分维度组合。

### 通用维度（所有决策都评）

| 维度 | 说明 | 评分标准 |
|------|------|----------|
| 风险可控性 | 最坏结果能否承受 | 1=不可控，10=完全可控 |
| 内心一致性 | 是否符合内心真正想要的 | 1=严重冲突，10=高度一致 |
| 长期复利 | 3 年后是否有积累 | 1=纯消耗，10=强复利 |

### 职业/创业类（额外评）

| 维度 | 说明 | 评分标准 |
|------|------|----------|
| 能力匹配 | 是否在能力圈内 | 1=完全不匹配，10=高度匹配 |
| 时机成熟度 | 外部条件是否具备 | 1=完全不成熟，10=条件成熟 |

### 关系类（额外评）

| 维度 | 说明 | 评分标准 |
|------|------|----------|
| 双方投入 | 对方是否也愿意投入 | 1=单方面，10=双方对等 |
| 边界清晰度 | 各自的责任是否明确 | 1=完全模糊，10=非常清晰 |

### 财务类（额外评）

| 维度 | 说明 | 评分标准 |
|------|------|----------|
| 流影安全边际 | 最坏情况下的承受能力 | 1=会破产，10=毫无影响 |
| 机会成本 | 放弃的替代方案价值 | 1=放弃巨大，10=几乎没有替代 |

## 评分输出格式

```
┌─────────────────┬──────┬──────────────────────┐
│ 维度            │ 分数 │ 说明                 │
├─────────────────┼──────┼──────────────────────┤
│ 风险可控性      │ 6/10 │ 现金流准备不足        │
│ 长期复利        │ 8/10 │ 如果方向正确有积累     │
│ 能力匹配        │ 7/10 │ 技术强，销售待验证     │
│ 时机成熟度      │ 5/10 │ 还缺客户验证          │
│ 内心一致性      │ 8/10 │ 明显向往自主创造       │
├─────────────────┼──────┼──────────────────────┤
│ 综合评分        │ 6.8  │ 有潜力但需补短板       │
└─────────────────┴──────┴──────────────────────┘

建议：先副业验证，不建议立刻裸辞
```

## 综合评分计算

综合评分 = 各维度分数的平均值，但需要根据问题类型加权：

- 风险类问题：风险可控性权重 x2
- 关系类问题：内心一致性权重 x2
- 创业类问题：时机成熟度权重 x1.5

## 评分原则

1. 评分不是目的，是为了让模糊问题变清晰
2. 任何维度低于 5 分都应该重点讨论
3. 综合评分低于 6 分，建议暂缓行动
4. 评分必须配合具体说明，不能只有数字
