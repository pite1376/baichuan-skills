# 用户长期画像

## 说明

此文件记录用户的长期画像，由系统在每次分析后自动更新。大师分析时会参考此画像，提供更个性化的建议。

## 画像维度

### 基础信息
- **当前阶段**：[创业早期/职业转型/学习积累/稳定发展/瓶颈期]
- **主要领域**：[AI Agent/内容创作/产品开发/...]
- **核心目标**：[用一句话描述]

### 行为模式
- **决策偏好**：[快速行动型/深思熟虑型/直觉驱动型]
- **常见问题**：[拖延/焦虑/目标太多/执行不稳/...]
- **能量周期**：[什么时间段状态最好]

### 能力画像
- **核心优势**：[技术理解/产品敏感/内容创作/...]
- **待提升项**：[销售/管理/沟通/...]
- **能力圈边界**：[明确知道自己不擅长什么]

### 风险模式
- **常见误判**：[高估短期机会/低估组织成本/...]
- **情绪触发点**：[什么事容易让用户焦虑/愤怒/逃避]
- **逃避模式**：[遇到什么问题容易绕开]

### 价值观
- **核心价值观**：[自由/成长/创造影响力/...]
- **底线**：[绝对不会做的事]
- **理想状态**：[3 年后想过什么样的生活]

## 更新规则

1. 每次分析后，检查是否有新的行为模式出现
2. 每 4 次分析更新一次画像总结
3. 如果发现重复出现的问题，在画像中标注
4. 画像只记录事实和模式，不做价值判断

## 使用方式

大师分析时参考画像：
- 芒格：检查用户是否在重复犯同样的误判
- 马斯克：根据能力圈边界调整方案难度
- 王阳明：对比内心真相和价值观是否一致
- 曾国藩：检查习惯模式是否在改善
