# 目录映射规则

## 从用户描述到目录的映射

根据用户访谈中提到的内容，映射到对应的目录。

### 关键词 → 目录

| 用户说的关键词 | 对应目录 | 说明 |
|--------------|---------|------|
| 上班、工作、公司、主业 | `10-work/` | 工作经验（脱敏后） |
| 副业、兼职、接单、自由职业 | `20-side-business/` | 副业想法和尝试 |
| 学习、考证、技能、课程 | `30-skills/` | 个人技能积累 |
| 项目、产品、开发、app | `40-projects/` | 个人项目记录 |
| 写作、公众号、自媒体、小红书、内容 | `50-content/` | 内容创作 |
| 理财、记账、投资、财务 | `60-finance/` | 财务记录 |
| 运动、健身、跑步、减肥、健康 | `70-health/` | 运动健康 |
| 感情、恋爱、社交、朋友 | `80-relationship-life/` | 关系生活 |
| 家庭、育儿、父母 | `85-family/` | 家庭事务 |

### 不确定的情况

如果用户提到的东西不好归类：
1. 先问清楚这个内容的性质
2. 如果是临时性的 → `00-inbox/`
3. 如果是长期积累 → 考虑是否需要新目录
4. 不要硬塞进已有目录

                    │

└──────────────────────────────────────────┘
                    │
┌──────────────────────────────────────────┐
│ 3. Resource Layer   外部资源层             │
│    09-resources/                          │

                    │

                    │
┌──────────────────────────────────────────┐

                    │

## 运行节奏设计

根据用户的时间分配，设计系统运行节奏：

| 用户类型 | 日记录 | 周复盘 | 月复盘 |
|----------|--------|--------|--------|
| 上班族 | 每天下班后 5 分钟 | 周日 15 分钟 | 月末 30 分钟 |
| 自由职业 | 每天随时 | 周日 | 月末 |
| 创业者 | 每天随时 | 周日 | 月末 |
| 学生 | 每天 | 周日 | 月末 |

## 隐私分级

| 级别 | 说明 | 处理方式 |
|------|------|---------|
| 绝对禁止 | 密钥、密码、客户名、合同 | 不记录 |
| 高风险 | 公司名、项目代号、内部系统 | 脱敏后记录 |
| 可记录 | 工作经验、踩坑、方法论 | 直接记录 |
| 公开区 | 脱敏后的内容 | 可发布 |
